# 音效教程：用代码"算"出声音

宣传片里的配乐和所有音效都没用任何素材，是用数学公式一个采样一个采样算出来的，只用了 Node.js。

这个目录是教学版：[mini-synth.mjs](mini-synth.mjs) 只有 273 行，带中文注释。运行后生成两段音频：

- [sounds_tour.wav](sounds_tour.wav)：把每个声音单独放一遍，依次是底鼓、军鼓、拍手、踩镲、贝斯、和弦、上升音、冲击音。
- [beat_demo.wav](beat_demo.wav)：把这些声音组合成一段 128 BPM 的蓄力 + drop。[频谱图](beat_demo_spectrum.png)能看出结构：左边是越来越密的军鼓和斜向上升的扫频，3.75 秒后是整齐的鼓点和贝斯。

```bash
npm run lesson    # 或 node lessons/sound-design/mini-synth.mjs
```

## 原理：声音就是一串数字

数字音频就是每秒 48000 个 -1 到 1 之间的数字，按顺序写进 WAV 文件就能播放。所以做音效就是写公式把这串数字算出来。所有声音都由四种零件拼成：

- **振荡器**（声源）：
  - 正弦波最纯净，适合低频。
  - 锯齿波最明亮，是电子合成器的主力。
  - 白噪声就是一串随机数，打击乐和"嗖"声都靠它。
- **包络**：控制音量随时间变化。比如 `Math.exp(-t * 7)`，瞬间起音再快速衰减，就有了"打"的感觉。
- **滤波器**：削掉一部分频率。低通让声音变闷，高通让它变薄，带通只留一段。截止频率随时间移动，就是常听到的"扫频"。
- **音高曲线**：频率随时间变化，底鼓的秘密全在这里。

拿底鼓举例，核心只有这几行：

```js
const SR = 48000, out = new Float32Array(SR / 2);  // 0.5 秒
let phase = 0;
for (let i = 0; i < out.length; i++) {
  const t = i / SR;
  const freq = 45 + 180 * Math.exp(-t * 40);  // 40 毫秒内从 225Hz 掉到 45Hz
  phase += 2 * Math.PI * freq / SR;           // 频率在变，所以要累加相位
  out[i] = Math.tanh(Math.sin(phase) * Math.exp(-t * 7) * 2);  // 衰减 + 饱和
}
```

## 每个声音的配方

| 声音 | 原料 | 关键技巧 |
|---|---|---|
| 底鼓 | 正弦 | 音高 225→45Hz 急降，再用 tanh 饱和变"胖" |
| 军鼓 | 正弦 + 噪声 | 180Hz 的"鼓皮"，加 3kHz 带通噪声当"响弦" |
| 拍手 | 噪声 | 1.2kHz 带通，3 个相隔 10 毫秒的短脉冲，模拟几只手先后拍到 |
| 踩镲 | 6 个方波 + 噪声 | 用 TR-808 的金属配方，频率互不成整数倍，只留 7kHz 以上 |
| 贝斯 | 锯齿 + 正弦 | 低通截止频率从 1650Hz 迅速落到 150Hz，出"嘟"的弹拨感 |
| 电子和弦 | 每个音 7 个锯齿 | 互相跑调 7~24 音分，左右分开，又宽又亮 |
| 上升音 | 噪声 | 带通频率从 300Hz 升到 11kHz，音量越来越大 |
| 冲击 | 正弦 + 噪声 | 超低频从 77Hz 滑到 27Hz 的"轰"，加一团噪声爆破 |
| 数据"哔哔"声 | 短正弦 | 降采样：每 6 个采样才更新一次，音量只留 15 级 |
| 打字声 | 噪声 + 高频正弦 | 12 毫秒的极短咔哒，每出一个字响一下 |

## 编曲和声画同步

用一个函数 `T(小节, 拍)` 把位置换算成秒数，128 BPM 下一拍是 0.46875 秒，然后按小节循环往上贴：

- 每拍一个底鼓。
- 第 2、4 拍拍手。
- 踩镲打 16 分音符。
- 贝斯躲开底鼓的位置。
- 和弦按 Fm → D♭ → A♭ → E♭ 循环。

在正片里，画面和音乐读的是同一份时间表（`src/timeline.js`）。合成器还会把每个鼓点的时刻导出成 `src/generated/events.js`，画面用它来触发闪光、缩放和光晕，所以声画天然对齐，不用手动卡点。

## 混音：让它像一首成品

- **侧链压缩**：底鼓一响，和弦和贝斯瞬间被压低再慢慢恢复，这就是电子乐那种"呼吸感"。
- **空间感**：加混响（Freeverb 算法）和左右交替的回声。
- **留白**：大爆发前留半拍静音，冲击会更强。
- **母带**：先用均衡器调频谱平衡，再用软削波和限幅器把响度推到 -10 LUFS，同时不爆音。

## 动手改改看

改几个数字再跑一遍，马上能听出区别：

- 把底鼓的 `180` 改成 `400`，鼓会更硬更"啪"。把 `exp(-t * 7)` 改成 `exp(-t * 2)`，会变成拖长的 808 低音鼓。
- 把拍手的 `1200` 改成 `2500`，声音更薄更脆。
- 把和弦的 `cents` 放大到 ±50，会更宽、更迷幻。
- 改 `BPM` 或和弦表，就是另一首歌了。

## 完整版在哪

正片用的合成器是 [src/audio/synth.mjs](../../src/audio/synth.mjs)，868 行。比教学版多了这几块：

- 全部乐器与音效（重击、碎裂、钟声、切片重复等）
- 整首曲子的编曲：按段落切换鼓组、贝斯、和弦、主旋律和琶音
- Freeverb 混响、乒乓延迟、侧链、母带均衡与真峰值限幅
- 固定随机种子，每次生成的 WAV 逐字节一致
